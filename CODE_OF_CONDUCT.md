# Kode etik

Komunitas ini kecil, jadi aturannya pun ringkas.

## Prinsip

- Bekerja dengan asumsi niat baik; kritik diarahkan ke kode dan metode, bukan ke orang.
- Data anggaran yang dianalisis proyek ini sensitif secara sosial. Dilarang memakai
  repo ini, issue, atau diskusinya untuk menyerang wilayah, instansi, atau pejabat.
  Temuan dibahas sebagai statistik, dengan batasan yang dijelaskan di
  `docs/METODOLOGI.md`.
- Hormati batasan akses server sumber data (cache, jeda permintaan).

## Cakupan

Berlaku untuk repo, issue, pull request, dan saluran komunikasi resmi proyek ini.

## Penegakan

Pelanggaran dilaporkan ke pengelola di `[email kontak pengelola]`. Laporan ditangani
dengan menjaga privasi pelapor. Pelanggaran berulang dapat berujung pada pemblokiran
akses ke repo dan saluran komunitas.

Catatan: ganti `[email kontak pengelola]` dengan kontak asli sebelum repo dibuka publik.
